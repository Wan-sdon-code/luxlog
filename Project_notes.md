# 📝 Python Script Notes

- `print()` → Shows words on the screen.
- Variables → Save the ballroom job information.
- `equipment_cost` → Works out the equipment cost.
- `staff_cost` → Works out the staff cost.
- `total_cost` → Adds equipment and staff costs together.
- `hotel_covers` → Shows how much the hotel covers.
- `if` → Checks if the cost is OK.
- `elif` → Checks if the cost needs attention.
- `else` → Shows when the cost is too high.

## 💡 What the Script Does

The program uses made-up ballroom data.

It calculates:

**Equipment cost:** 8 × $30 = **$240**

**Staff cost:** 5 × $20 = **$100**

**Total cost:** $240 + $100 = **$340**

**Client paid:** $0

So the hotel covers:

**$340**

The result is:

**🟠 CHECK**

The idea is simple:

> **Complimentary for the client does not mean there is no cost to the hotel.**
